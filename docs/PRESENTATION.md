# Agentic SDLC: presentation notes

## Thirty-second introduction

Agentic SDLC is an experimental, on-demand engineering coordinator for Claude Code, Cursor and Codex. It turns an unclear request into focused discovery, an agreed design and a phase-based engineering process. It discovers capabilities and invokes specialists, skills and existing MCP connections only when needed.

It includes brainstorming, Ponytail, Graphify and UI/UX Pro Max instruction assets, native host adapters and a seventeen-runtime catalog. Ten runtime recipes are enabled after Windows local checks. Seven tools remain blocked, so this is not the complete automatic bundle yet.

## Demonstration

1. Follow [the installation guide](../INSTALL.md) in a disposable project using the actual host.
2. Show `install` and `doctor` JSON. Separate installed/smoke-tested tools from provider setup, project integration and blocked tools. Explain exit 1 honestly.
3. Invoke `/agentic-sdlc` in Claude Code/Cursor or `$agentic-sdlc` in Codex. Native full workflow behavior is not yet certified, so label a narrated discovery example as a walkthrough.
4. Explain the initial conversation: reuse supplied facts; ask for missing goal, audience, success criteria, constraints and authority; ask relevant UI/reference/prototype questions; detect technical capabilities itself.
5. Show the implemented resume, diagnostic, update, rollback and uninstall commands. Modified and unknown files are preserved, and private state authenticates runtimes before reuse.

## Evidence and remaining work

The current configuration build ran 166 tests: 163 passed, three platform/privilege skips, no failures. An extracted source package passed 34 asset/catalog checks. Selected local profiles are configured and checked through configure/project-doctor after discovery; application integration remains separate. Real local operations and lifecycle scope are recorded in [runtime status](runtime-status.md).

The seven remaining tools have unresolved dependency, security or Docker gates. Full native Claude/Cursor/Codex workflows, clean-device installation and macOS/Linux support remain unverified. No production-readiness claim is justified. Source is available at https://github.com/sarpanch132/agentic-sdlc; older experimental ZIPs are stale.
